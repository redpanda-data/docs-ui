[#prod-brokers-and-replication]
== Brokers and replication

Run at least three brokers and set the replication factor of every topic to 3.

[#prod-client-placement]
== Client placement

Run the producers, the services, and the Connect pipeline in the same cloud provider and region as the cluster.

[#prod-security]
== Security

Turn on TLS and SASL/SCRAM, and give each service its own principal with the ACLs it needs.

[#prod-partitions]
== Partitions

Size partitions for the peak event rate, not the average.

[#prod-schema-validation]
== Schema validation

Turn on server-side schema ID validation so a producer cannot write an unregistered schema.

[#prod-consumer-scaling]
== Consumer scaling

Scale each consumer group on lag, up to one instance per partition.

[#prod-data-retention]
== Data retention

Keep raw events for as long as you need to replay them, and compact the leaderboard topic.

[#prod-observability]
== Observability

Alert on consumer lag, under-replicated partitions and schema registration failures.

[#prod-disaster-recovery]
== Disaster recovery

Replicate the topics to a second region with Shadowing.
