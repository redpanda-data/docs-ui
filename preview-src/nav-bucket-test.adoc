Exercises both version pickers against the fixture data in `preview-src/ui-model.yml`.

The **sidebar** picker (per bucket, from `page-custom-navigation`) should keep you on the
current page when the page exists in the target version, and dim the entry with a tooltip
when it does not. `ui-model.yml` marks version 5.0 as missing, so v5.0 is the entry that
should render dimmed and italic. Streaming has eight versions, so the newest five show and
the rest sit behind "Show 3 older versions". The Connect bucket belongs to a different
component, so every one of its options correctly points at that version's home page.

The **article pill** ("Docs for vX") shows the same missing-page treatment in its grouped
panel.

NOTE: The preview build supplies no Antora content catalog, so only the `page.versions`
resolution path is exercised here. The catalog fallbacks (`family: 'page'`, then
`family: 'alias'`) are covered in `tests/version-picker/`.
