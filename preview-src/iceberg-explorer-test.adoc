= Iceberg Mode Explorer
:page-layout: default
:page-no-toc: true
:description: Interactive explorer for Redpanda Iceberg mode key/value/header translation.

Pick a configuration and see the DSL config string, the resulting Iceberg table
schema, and a sample translated record update live.

The markup below replicates the output of the `[iceberg-explorer]` block
macro in docs-extensions-and-macros (`macros/iceberg-explorer.js`), so this
preview does not depend on that package.

Each mount waits for the engine built from the Redpanda release it documents.
On a docs page the layout finds it among the streaming reference attachments.
Here every mount points `data-engine-base` at `/_attachments`, which holds the
v26.1.1 and v26.2.1 engines (`iceberg-editor/wasm/build.sh web`, copied with a
provenance `.json`). They exist only for this preview: the UI bundle carries no
engine. The engine decides which choices the controls offer. A mount whose
engine is missing, or built from another release, keeps its fallback text.
