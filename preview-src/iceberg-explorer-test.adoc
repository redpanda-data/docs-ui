= Iceberg Mode Explorer
:page-layout: default
:page-no-toc: true
:description: Interactive explorer for Redpanda Iceberg mode key/value/header translation.

Pick a configuration and see the DSL config string, the resulting Iceberg table
schema, and a sample translated record update live.

The markup below replicates the exact output of the `[iceberg-explorer]` block
macro in docs-extensions-and-macros 5.60.0 (`macros/iceberg-explorer.js`), so this
preview does not depend on that package. The `page-version` attribute is unset
here, so the macro emits no `data-version`.

Source: `[iceberg-explorer]` with an empty open block.
