= Meaning System Test
:page-layout: default
:description: Every meaning badge and notice from src/css/meaning.css, for checking color, contrast, and tooltips in light and dark.

Every meaning on the docs site has one look: the badges and notices below. Colors come from the `--meaning-*` tokens in `vars.css` and `dark-mode.css`, icons from the `--icon-*` tokens. Switch the theme to check dark mode. Hover, focus (Tab), or tap a badge to see its tooltip: every `data-tooltip` element gets the same tippy tooltip from `12-activate-tooltips.js`.
