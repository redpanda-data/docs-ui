= Macro Tooltips Test
:page-layout: default

Test page for the hover tooltips on the inline `blobl:`, `connect:` and `rpkcmd:` macros (src/js/28-macro-tooltips.js). Each reference below is the macros' real HTML output, captured from docs-extensions-and-macros through Antora's converter, pasted as pass-through HTML because the UI preview doesn't run the docs macros.

The data comes from two trimmed fixtures, which the preview copies to the UI root: preview-src/_data/connect.json (from connect-4.115.1.json in rp-connect-docs) and preview-src/_data/rpk.json (from docs-data/rpk-v26.2.2.json in docs, in the shape of the published rpk-<version>.json attachment). A tooltip only ever shows what the data says. When the data or the entry is missing, there is no tooltip.

A reference with a tooltip has a dotted underline under its code. Hover it, or move focus to its link with kbd:[Tab]. Press kbd:[Esc] to close the tooltip. On a touch device, a tap opens the tooltip instead of following the link, and the tooltip's footer link goes to the reference page.

== Bloblang functions and methods

The function +++<a href="../../../connect/guides/bloblang/functions/#now" class="xref page"><code class="bloblang-call" data-bloblang-function="now">now()</code></a>+++ returns the current time.

* You should see: the signature `now()` and the first paragraph of its description ("Returns the current timestamp as an RFC 3339 formatted string..."), no parameters, and a View full documentation link to `functions/#now`.

The function +++<a href="../../../connect/guides/bloblang/functions/#counter" class="xref page"><code class="bloblang-call" data-bloblang-function="counter">counter(min)</code></a>+++ names a parameter.

* You should see: the signature `counter(min, max, set)` and a parameter list with defaults: `min` (query expression, default: `1`), `max` (query expression, default: `9223372036854776000`, the value the data holds) and `set` (query expression, optional, no default).

The method +++<a href="../../../connect/guides/bloblang/methods/#uppercase" class="xref page"><code class="bloblang-call" data-bloblang-method="uppercase">.uppercase()</code></a>+++ converts a string.

* You should see: the signature `uppercase()` and "Converts all letters in a string to uppercase", with no parameters.

=== A method in several categories

`contains` is listed under two categories on the methods page. The macro links a different copy for each category, but marks the same name, so both show the same tooltip and differ only in the footer link.

With the default category: +++<a href="../../../connect/guides/bloblang/methods/#contains" class="xref page"><code class="bloblang-call" data-bloblang-method="contains">.contains()</code></a>+++.

With `category=String Manipulation`: +++<a href="../../../connect/guides/bloblang/methods/#contains-2" class="xref page"><code class="bloblang-call" data-bloblang-method="contains">.contains()</code></a>+++.

* You should see: on both, the signature `contains(value)`, "Tests if an array or object contains a value", and the parameter `value` (unknown). The footer link goes to `methods/#contains` on the first and `methods/#contains-2` on the second.

== rpk commands and flags

The command +++<a href="../../26.2/reference/rpk/rpk-topic/rpk-topic-create/" class="xref page"><code class="rpk-command" data-rpk-command="rpk topic create">rpk topic create</code></a>+++ creates topics.

* You should see: the usage line `rpk topic create [TOPICS...] [flags]` and "Create one or more Kafka topics with configurable partitions, replication factor, and topic-level settings."

The flag +++<a href="../../26.2/reference/rpk/rpk-topic/rpk-topic-create/" class="xref page"><code class="rpk-command" data-rpk-command="rpk topic create" data-rpk-flag="partitions">rpk topic create --partitions</code></a>+++ sets the partition count.

* You should see: `--partitions`, `-p`: `int32`, its description ("Number of partitions for the topic..."), Default: `-1`, and "Flag of rpk topic create".

The shorthand +++<a href="../../26.2/reference/rpk/rpk-topic/rpk-topic-create/" class="xref page"><code class="rpk-command" data-rpk-command="rpk topic create" data-rpk-flag="partitions">rpk topic create -p</code></a>+++ is the same flag.

* You should see: the same tooltip as `--partitions`. The macro writes the long name into the marker for a shorthand.

The global flag +++<a href="../../26.2/reference/rpk/rpk/" class="xref page"><code class="rpk-command" data-rpk-command="rpk" data-rpk-flag="profile">rpk --profile</code></a>+++ picks a profile.

* You should see: `--profile`: `string` and "rpk profile to use", with no default line: the data's default is an empty string, which says nothing.
